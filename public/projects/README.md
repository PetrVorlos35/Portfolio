# Project screenshots

Screenshots here are used as the hero image on case study pages
(`/projects/<slug>`), referenced via `hero` in `content/caseStudies.ts`.
Recommended: ~1200×900 (4:3), PNG or JPG, optimized.

- `journeo.png` — Journeo
- `outlay.png`  — Outlay

Mobile-first projects use `screens` instead: a row of portrait phone
screenshots (straight from the phone, e.g. 924×2000, optimized). Any file
that's missing is simply skipped.

- `splitee-1.png`, `splitee-2.png`, `splitee-3.png` — Splitee

The home page project list is intentionally text-only (no thumbnails);
the case studies carry the imagery.
